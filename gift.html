CRM 엑셀을 올리면 ‘금액’ 이체 양식과 ‘추가사은품’ 이체 양식, 2개 파일을 자동으로 만들어드려요.

CRM 엑셀 파일을 올려주세요
.xls / .xlsx 파일 (CRM에서 다운로드한 그대로)
파일 1 · 금액 기준 이체
파일 2 · 추가사은품 기준 이체
지급완료 현황
개통일별 현황 (지급완료 기준)
적용 규칙
입금은행 · 입금계좌번호 ← CRM ‘사은품은행(AC)’ · ‘사은품계좌(AD)’
이체금액 ← 파일1(사은품)은 ‘금액’, 파일2(추가사은품)은 ‘추가사은품’ (각 0원 제외)
내통장인쇄내용 ← ‘고객명’에서 ‘/’ 앞부분(이름)만 사용
받는분통장인쇄내용 ← “인터넷 지원금” 고정
CMS코드 ← 공란
지급완료(W열)에 날짜가 있는 행 ← 중복입금 방지를 위해 이체 대상에서 자동 제외
상품명(C열)에 ‘TV’·‘전화’가 포함된 행 ← 금액이 있어도 이체 대상에서 자동 제외 (검증용)
사은품은행(AC)·사은품계좌(AD) 누락 행 ← 이체 불가로 자동 제외 (목록으로 별도 표시)
1건 이체금액이 50만원 초과인 행 ← 제외하지 않고 그대로 포함, 대신 확인 알림 표시
개통일(L열)-지급예정일 차이가 7일 이상인 행 ← 제외하지 않고 그대로 포함, 대신 확인 알림 표시
파일명 ← “YYMMDD 사은품.xlsx” / “YYMMDD 추가사은품.xlsx”
개통일별 현황 ← 지급완료 건 중 계좌정보 있는 건만, 고객 단위로 합산해 개통일별 리스트·합계 생성 (개통일 변경 여부 확인용)
업로드한 파일은 서버로 전송되지 않고 이 화면 안에서만 처리돼요.
